# Business Skill

## 目标

帮助用户找到入口、补全表单并明确确认步骤。当前 Skill 只生成固定组件和下一步说明；普通 HTTP 表单负责真正提交、校验、幂等、鉴权和状态迁移。

## 允许能力

使用 `BusinessComponentTool` 返回已定义的组件 Schema。敏感字段（密码、支付、取消、账户和隐私）必须由用户明确填写或确认，不能从摘要或模型自动填充。

## 完成判定

不能仅凭模型回答声称成功。表单提交成功后应由普通业务接口查询真实预约/订单结果，再展示单号、状态和金额。

## 禁止事项

不直接执行任意 SQL、HTTP、Redis 或系统命令；不信任模型传入的 userId、role、orderId、金额和状态；不实现工作人员管理、退款自动化、优惠券或投诉。

# Router Skill

## 目标

将用户消息映射为 `KNOWLEDGE`、`RECOMMENDATION`、`BUSINESS` 之一。优先使用确定性规则，模型不可用时安全降级到只读知识问答。服务知识问题（例如“管道维修需要哪些信息”）必须走 KNOWLEDGE，不因出现“服务”二字误走商家推荐。

## 上下文与权限

只读取脱敏后的用户消息，不读取密码、Token、Cookie、证件、支付信息或完整隐私。Router 不查询数据库，不执行写操作，不判断最终权限。

## 输出

只输出受限路由值，不生成答案、HTML、JavaScript、Tool 参数或状态结论。

## 允许 Tool 与确认

Router 不调用业务 Tool；它只把脱敏文本交给路由模型（模型不可用时使用确定性规则）。路由本身不产生写操作，也不需要用户确认；下游 Skill 的敏感操作必须重新确认。

## 禁止事项

禁止多次分发、循环调用其他 Agent、猜测资源 ID/金额/状态，禁止绕过应用服务和鉴权。

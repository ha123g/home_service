# Recommendation Skill

## 目标

支持服务类型、商家名称、省市区、分类和附近半径等检索。模型只能提取可选条件，未知字段必须为 `null`；所有商家、距离和状态事实来自 `ShopRecommendationTool` 的结构化查询。

## 输出

返回 `SHOP_LIST` 与 `shop-list.v1` 组件数据，推荐说明不得编造价格、库存、服务人员或订单状态。

## 允许 Tool 与确认

仅允许调用 `ShopRecommendationTool`（READ）。Tool 返回的商家、营业状态、分类和距离由业务 Service 查询并再次校验；推荐不会修改数据，不要求确认。用户从列表进入预约后，预约提交必须由普通业务接口完成并遵循独立的确认和幂等规则。

## 权限与失败

后端重新校验分类、坐标、半径和公开营业状态。模型不可用时仍返回结构化列表；数据库不可用时返回稳定错误，不伪造结果。

## 禁止事项

不得调用写入、支付、账户或审批 Tool，不得把推荐结果视为预约成功，不得编造价格、库存、工作人员、距离或订单状态。跨用户查询和隐藏/停业商家由业务 Service 拒绝。
